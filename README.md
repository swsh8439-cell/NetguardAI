**NetGuard AI** is a **Machine Learning-based Network Intrusion Detection System (IDS)** designed to monitor network traffic and identify potentially malicious activities.

- **Dataset:** Synthetic CIC-IDS2017-inspired network-flow data
- **ML Algorithm:** Random Forest Classifier
- **Detects:** Normal Traffic, DoS/DDoS, Port Scan, Brute Force, Web Attack, and Botnet
- **Output:** Attack classification with prediction confidence
- **UI:** Live Traffic, Alerts, Attack Analysis, Logs & Model Performance

### 🔄 System Flow

`Network Traffic → Preprocessing → Feature Extraction → ML Model → Attack Detection → Alert → Dashboard`
